# DS_Basic_Analysis_Python
## 📘 데이터 과학 기반의 파이썬 빅데이터 분석 실습
> **이지영 저, 한빛아카데미** 책을 학습하며 정리하는 저장소입니다.

<br/>

## 📝 프로젝트 개요
이 저장소는 파이썬을 활용한 빅데이터 분석의 기초부터 실무 기법까지, 도서 내 실습 예제와 연습 문제를 직접 코딩하며 학습한 내용을 담고 있습니다.

- **학습 목적**: 데이터 수집, 정제, 분석 및 시각화 프로세스의 숙달
- **사용 환경**: Google Colab
- **주요 스택**: Python, Pandas, NumPy, Matplotlib, Seaborn
